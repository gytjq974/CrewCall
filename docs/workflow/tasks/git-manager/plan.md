# Git 형상관리 담당자

2026-11-25 · 사용자가 기획과 구현을 승인했다.

사용자는 기획 채팅에서 Git 작업을 요청한다. 기획 담당자는 대상 저장소와 요청 범위를 Git 형상관리 서브에이전트에게 전달하고, 실제 반영된 브랜치와 커밋 또는 진행을 막은 사유를 받아 보고한다. 형상관리 역할의 기본값은 `gpt-6.2-sol`, 추론 수준은 `low`다.

## 역할과 완료 조건

- **Pull** 요청을 받으면 현재 브랜치와 추적 대상을 확인해 변경을 가져온다. 충돌 해결에 제품 코드 수정이나 사용자 결정이 필요하면 기획 담당자에게 돌려준다.
- **Push** 요청에 브랜치 이름이 없으면 현재 체크아웃한 로컬 브랜치와 같은 이름의 원격 브랜치에 푸시한다. 예를 들어 로컬 `feature/login`에서 요청하면 원격 `feature/login`에 반영한다.
- **대상을 지정한 push**는 현재 작업 브랜치의 커밋을 지정한 원격 브랜치에 반영한다. 로컬 `feature/login`에서 “`develop`에 푸시해줘”라고 하면 원격 `develop`으로 보내고 로컬 작업 브랜치는 유지한다. 대상에 일반 푸시가 거절되면 그 사유를 보고한다.
- **커밋과 푸시**를 함께 요청하면 승인한 파일만 커밋한다. 개발 테스트 결과의 재사용, 한글 커밋 메시지 본문의 ‘변경 이유’와 ‘주요 변경’, 기존 커밋을 그대로 푸시하는 기준은 현재 [Git 지침](../../../../skills/crewcall/references/verification.md#git-반영과-커밋-메시지)을 따른다.
