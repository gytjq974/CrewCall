# 기획 · 현재 코드에서 가능한 설계와 공용 로드맵

사용자는 설계 담당자가 실제 코드로 기획을 달성할 수 있는지 확인하기를 원한다. 요구를 충족할 수 없거나 기획의 수단이 목표와 어긋날 때는 근거와 가능한 수정 방향을 메인에게 돌려 사용자가 결정한다.

- 설계 전에 프로젝트 전체의 주요 진입점·데이터 흐름·검사 위치를 찾을 수 있는 로드맵을 준비한다.
- 설계·구현·테스트 담당자는 같은 파일에서 시작해 해당 코드와 데이터를 직접 확인한다.
- 코드·테스트가 바뀌면 완료 시 그 부분을 최신화한다. 다음 작업에서는 그 문서를 이어 쓴다.
