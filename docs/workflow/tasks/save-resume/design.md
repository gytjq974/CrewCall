# CrewCall의 작업 기록 방식

[기획과 완료 조건](plan.md)

- 메인은 대상 프로젝트의 기존 문서를 먼저 찾는다. 기본 경로에서는 한 작업의 기획서와 설계서를 같은 작업 폴더에 두고, 실제로 진행한 단계만 작성한다.
- 메인은 작업을 시작하면 최근 작업 파일을 갱신한다. 단계가 바뀌거나 사용자 결정·위임·수정·검증 결과가 생기면 같은 파일의 현재 단계와 다음 행동을 고친다.
- 새 채팅에서 스킬만 실행해도 최근 작업 파일을 먼저 찾는다. 기획서와 설계서 링크를 열고 진행 상태를 실제 파일과 대조한 뒤, 허용된 단계부터 이어간다.
- 실습 프로젝트에서 첫 메인에게 기획·설계까지만 맡긴다. 이전 대화를 받지 않은 두 번째 메인에게 스킬과 작업 폴더만 알려 주고, 재개 전후에 기록과 제품 파일을 각각 확인한다.
