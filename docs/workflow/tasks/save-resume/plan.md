# 기획과 설계를 파일로 남기고 새 채팅에서 이어가기

사용자는 기획서와 설계서를 다른 채팅의 담당자가 직접 읽고, 개발 도중 메인 채팅을 바꾸더라도 마지막으로 하던 일을 이어가기를 원한다.

| 완료 조건 | 확인할 결과 |
|---|---|
| 문서 보존 | 기획이나 설계를 진행하면 해당 단계의 내용이 대상 프로젝트에 파일로 남는다. 다른 담당자가 경로를 받아 열 수 있다. |
| 이어받기 | 이전 대화가 없는 메인이 최근 작업 파일에서 기획·설계, 현재 상태와 다음 행동을 찾는다. |
| 사용자 결정 보존 | “구현은 기다려줘”라는 지시가 있으면 새 채팅도 대기한다. 이후 같은 작업에 대한 명시적 시작 지시를 받으면 그 설계로 진행한다. |

이번 범위는 같은 프로젝트 파일에 접근할 수 있는 채팅 간의 인계다. 계정이나 기기 사이 파일 동기화는 다루지 않는다.
