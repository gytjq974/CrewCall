## 의도적인 조정

- 변환 당시 원본은 대조용으로 사용했다. 앞으로의 스킬 수정 기준은 skills/crewcall이다.
- 역할과 실행 수단을 구분했다. 환경에서 허용된 서브에이전트 또는 사용자가 명시적으로 요청한 별도 채팅을 사용하며, 실제 식별자를 구분한다.
- 스킬 호출이 범위 밖 작업이나 배포의 허가가 되지 않음을 명시했다.
- 상세 문서의 적용 시점을 진입점에 연결했다. 전체 참조 문서를 항상 읽도록 강제하지 않는다.

## 시나리오별 정적 검토

| 요청 또는 상황 | 지침에서 확인한 기대 행동 | 근거 |
|---|---|---|
| 기획만 요청 | 기획 산출물에서 종료 | SKILL.md의 처음 시작하거나 이어받을 때, planning.md |
| 작은 기능 수정 | 기본 단독 경로, 필요한 검증 후 완료 | SKILL.md의 작업 경로와 승인, verification.md |
| 정식 협업 지정 | 설계·구현 시작 지시와 필수 검토 적용 | SKILL.md의 작업 경로와 승인 |
| 로그 원인 조사만 요청 | 조사 범위에서 종료, 수정하지 않음 | SKILL.md의 시작·재개 및 작업 경로와 승인, debugging.md |
| 기존 작업 재개 | 기존 승인·변경·미회수 요청을 확인하고 중복 발송 방지 | SKILL.md의 처음 시작하거나 이어받을 때, project-state.md |
| 독립 테스트 실행 불가 | 자체 확인으로 대체 판정하지 않고 대기 상태 보고 | collaboration.md, verification.md |

위 시나리오는 지침의 정적 검토다. 별도 에이전트의 실제 행동 평가나 대상 프로젝트에서의 개발 실행 테스트는 수행하지 않았다. 형식 검사와 원문 대조만으로 실제 모델 행동까지 보장하지 않는다. 전역 설치와 자동 발견 여부 확인도 이번 작업에 포함하지 않았다.
